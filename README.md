# CodePet Web

Web dedicada de CodePet, preparada para publicarse en GitHub Pages.

## Incluye

- Landing responsive y página de privacidad.
- Selector de idioma ES/EN, tema claro/oscuro y navegación móvil.
- SVG originales reutilizados desde `CodePet/docs/assets/` y capturas de la app.
- Workflow `.github/workflows/pages.yml` para despliegue automático.

## Publicación

1. Crea un repositorio de GitHub para esta carpeta, por ejemplo `CodePet-Web`.
2. Sube el contenido a la rama `main`.
3. En **Settings → Pages**, selecciona **GitHub Actions**.

El sitio usa rutas relativas y quedará disponible en `https://<usuario>.github.io/CodePet-Web/`.
